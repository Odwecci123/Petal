# Petal

Браузер с вкладками слева и набор функций: саундпад (с выводом звуков в микрофон), калькулятор,
случайные числа, колесо удачи. Есть история, менеджер паролей, режим инкогнито, восстановление вкладок.
Только для Windows 10 и 11.

## Как установить (для пользователей)

1. Откройте страницу **Releases** этого репозитория.
2. Скачайте `Petal-Setup-….exe`, запустите и пройдите установку.
3. Если Windows пишет «Система Windows защитила ваш компьютер», нажмите «Подробнее» и «Всё равно выполнить»:
   программа пока не подписана цифровой подписью.

Без установки: скачайте `Petal-portable-….zip`, распакуйте куда угодно и запустите `petal.exe`.
Данные в этом случае лежат рядом с программой.

Данные установленной версии (вкладки, история, звуки, профиль браузера) лежат в `%LOCALAPPDATA%\Petal`.
При удалении программы они остаются, их можно стереть вручную.

### Звук в микрофон

Нужен бесплатный виртуальный кабель [VB-CABLE](https://vb-audio.com/Cable/) (ставится отдельно, перезагрузка).
В Саундпаде включите «Играть звуки в микрофон», а в Discord или игре выберите микрофон «CABLE Output».

## Как выпустить новую версию (для автора)

1. Поднимите `version` в `Cargo.toml`.
2. Отправьте код на GitHub.
3. Создайте и отправьте тег: `git tag v1.0.1` и `git push origin v1.0.1`.
4. Вкладка **Actions** соберёт программу и установщик, а на странице **Releases** появятся файлы для скачивания.

Сборка на своём компьютере: `cargo run --release`. Установщик собирается в Inno Setup из `installer/petal.iss`.
